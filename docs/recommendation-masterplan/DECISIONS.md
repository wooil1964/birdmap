# 결정 기록

## 사용자 지시로 확정된 작업 조건

- 이번 프로젝트는 P1~P4 연구·분석·설계이며 구현·배포에는 별도 승인이 필요하다.
- 분석 문서와 필요한 분석 전용 도구만 전용 브랜치에 commit/push한다. main/P0 기능 브랜치에서 작업하지 않는다.
- 각 주요 분석 단위 완료 때 확인 사실/가설·SHA/자료 시각·남은 일/다음 작업을 저장한다.
- P0 안전, 기존 기능·데이터·조위 기준, 민감종/번식지 보호는 약화하지 않는다.
- 운영 코드/자동 JSON/Worker/D1/실제 제보·현장소식에는 쓰기를 수행하지 않는다.
- 첫 세션은 기준·흐름·우선순위·문서와 P1-A 정량 분석 착수까지다.

## 분석 운영 선택 (제품 정책 승인이 아님)

- 사용자 예시에 따라 `analysis/recommendation-masterplan` 브랜치를 사용한다.
- main `1f0b0b5ca9d3ef887fc0bd2a159ef73429466a25`에 고정하고 별도 승인 제보 집계의 취득 시각과 해시를 기록한다.
- 새 가점이나 확률을 만들지 않고 현재 함수 그대로 추출해 재생한다.
- 첫 단계에서는 원점수·적격·후보·표시·내부 rankScore를 분리한다.

## 보류·미승인

새 배점, 확률 모델, 동점 처리 방식, 최대16 가점 변경, 정원 변경, 생태/관심종 데이터, 신규 API, UX와 위치 활용, 운영 롤백 방식의 제품 적용은 확정되지 않았다. 구현 승인도 없다.
