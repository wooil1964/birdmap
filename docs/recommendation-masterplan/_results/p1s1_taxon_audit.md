# P1-S1 독립 종명·오탐 계약 검토

확인일: 2026-10-09. 저장소 `reports-api/src/shared.js`를 읽기 전용으로 확인했다. 이 보고서는 정책/문자열 판정 설계이며 실제 운영 유출 또는 실제 관찰종·개체수를 판단하지 않는다.

## 확인된 사실과 정책 범위

- 현행 위치 보호는 19종 문자열 목록의 정확한 `includes`와 6개 번식 관련 키워드의 부분문자열 검색이다. 법정 보호종 전체 목록이라는 주석/계약은 확인하지 못했다.
- [국립생태원 저어새](https://www.nie.re.kr/nie/pgm/edSpecies/view.do?menuNo=200121&speciesSn=27), [흰꼬리수리](https://www.nie.re.kr/nie/pgm/edSpecies/view.do?menuNo=200121&speciesSn=34), [매](https://www.nie.re.kr/nie/pgm/edSpecies/view.do?menuNo=200121&speciesSn=25) 직접 조회로 각 국명과 서로 다른 학명 표기를 확인했다. 이들 표기 변형을 현행 정책대로 막는 것은 기존 정책 방어 보완이다.
- [NIBR 2020년 서해5도 연구 목록](https://www.nibr.go.kr/aiibook/access/ecatalogt.jsp?Dir=1007&callmode=admin&catimage=&eclang=ko&start=92&um=s)은 한국동박새와 동박새를 별도 항목으로 기재한다. 역사적 자료로도 임의 병합을 뒷받침하지 않는다. 최신 전체 taxonomy 확정은 별도 필요하다.
- [NIBR 2022~2023 센서스 56~57쪽](https://www.nibr.go.kr/aiibook/access/ecatalogt.jsp?Dir=1269&callmode=admin&catimage=&eclang=ko&start=56&um=s)에서 갈매기류 및 알락오리·알락할미새의 별도 국명을 확인했다. `매`를 단순 부분문자열 검색하면 갈매기류를, `알`을 단순 부분문자열 검색하면 알락 종명을 오탐한다.
- 새매·검은머리갈매기는 현행 19종 목록 미포함을 법정 비보호로 해석할 수 없다. 이들을 “정상 일반종” 오탐 분모로 쓰지 않는다. 보호정책 목록 확대는 사용자 승인과 최신 공식 목록 검토가 필요한 별도 정책 결정이다.

## 권고 토큰 계약

1. 원문 species/note를 저장 당시 형태로 보존한다. 파생 판정만 추가하며 과거 저장 문자열을 일괄 덮어쓰지 않는다.
2. LF·CRLF를 제어문자 제거 전에 허용 구분자로 토큰화한다. 쉼표, 세미콜론, 중점 및 요청된 슬래시도 명세로 명확히 허용한다. slash를 기존 API에 허용하는 것은 입력 계약 확대이므로 테스트와 버전 기록을 요구한다.
3. 각 토큰은 NFC 정규화와 양끝 공백 정리만 기본 적용한다. 내부 공백이나 모든 숫자를 일괄 삭제하지 않는다. NBSP 등 어떤 공백을 수량 경계에 허용할지 명시한다. 제로폭/방향 제어문자는 몰래 삭제 후 확정하지 말고 review로 분류한다.
4. 정확한 사전 국명을 먼저 조회한다. 실패 시에만 **검증된 국명 + 완전한 수량 접미사 문법** 후보를 검사한다. 수량은 ASCII 정수 1~기존 `MAX_BIRD_COUNT=100000`, 선택적 공백과 `마리` 단위의 전체 일치를 최소 허용안으로 삼는다. 0·음수·소수·지수·범위·약·물음표·앞쪽 숫자·상한 초과는 확정 수량으로 만들지 않는다. 명확한 기존 보호종 또는 review 입력이면 둘 다 정확 위치/집계/가점을 보류한다.
5. 현재 `birdCount`는 행 전체 수량이며 문자열별 수량과 서로 다른 정보다. 양자가 모순될 때 합산·덮어쓰기하지 않는다. 수량 추출은 민감정보 판정에 쓰되 제보 가점 다양성 산식 변경은 별도 정책이다.
6. 종명 판정, 수량 유효성, 보호 여부, 번식 여부, 공개 적격을 별도 상태로 반환한다. `unknown`을 일반종 확정으로 바꾸지 않는다. 원문과 검증된 canonicalName을 구분하며 검증하지 않은 taxonId·alias를 만들지 않는다.
7. 혼합 종 행의 한 종 또는 자유 서술의 민감정보가 불확실하면 행 전체의 정확 위치, spot/site 연결, 길안내와 최근집계/가점을 보류한다. 다른 일반종만 뽑아 공개하면 같은 위치를 역으로 유추할 수 있다. 과거 승인 사실이 현재 공개 보호 재검증을 생략하는 근거가 되지 않는다.
8. 기존 6개 번식 키워드 보호를 완화하지 않는다. 요청된 `알`은 단독 명사/명확한 수량·한국어 조사 경계 등 합의된 문법으로 추가하고 `알락*`, `알 수 없음` 반례를 함께 둔다. 형태소 처리 범위와 부정 표현·인용·일반 문맥은 실제 표본 없이 생태학적으로 검증됐다고 주장하지 않는다.

## 대안 비교

- A. 작은 공유 read-time 보호 판정 함수 + 버전된 최소 명칭 사전: Worker 공개 직렬화/집계와 승인 보호에서 같은 판정을 사용하고 기존 저장값과 응답 구조를 보존한다. D1 migration은 없어도 가능하다. 기존 19종 변형·unknown 보류가 우선이다. 사전 범위가 좁으면 정상 제보 review가 증가할 수 있어 production adoption 전 정상 표본 영향 측정이 필요하다.
- B. 별도 canonical species record/taxonId/수량 + policyVersion 판정 필드를 저장하고 UI 선택형 입력: 장기적으로 자료 연결과 재검증을 명확히 하지만 Worker·프런트·D1 확장이 커지고 rollback 시 구버전 무시 가능성이 생긴다. 전체 taxonomy 데이터 검증 및 이력 설계가 필요하다.
- 양안 모두 공개 read-time 재검증을 생략할 수 없다. approval status는 관리자 업무 상태이며 safe-to-publish가 아니다.

## 오탐·누락 측정 분모

- 보호 미차단률: known policy protected 및 명확한 breeding fixtures 중 정확 위치/추천 연결이 허용된 건수 / 그 fixture 수.
- 정상 오탐률: 공식 명칭이 확인되고 현행 정책 보호·번식 조건이 없는 정상 fixtures 중 불필요하게 withheld 또는 review 된 건수 / 그 fixture 수. 입력 validation reject, 위치보류, 최근 집계제외는 각각 별도 보고한다.
- unknown/review 보류율은 위 정상 분모에 넣어 보호 오탐처럼 해석하지 않는다. 최소 사전에서 정상 국명 누락으로 review 된 경우는 **사전 coverage 문제**로 별도 분모 보고한다.
- 현행 정책 미포함이나 법정 보호 검토 대상(예: 새매, 검은머리갈매기)은 별도 정책 범위 군이다. 전체 법정 목록 도입 전 이들을 일반종 분모로 집어넣지 않는다.
- 합성 fixture 통과율은 실제 운영 오탐률이 아니다. 본 검토에서는 운영 D1/API 자료를 내려받지 않았다.

## 최신 사전 확보 조건과 남은 불확실성

[NIBR 2026-02-09 공식 발표](https://www.nibr.go.kr/cmn/board/SYSTEM_DEFAULT000004/67140bbsDetail.do)에서 2025년 말 국가생물종목록의 공개/연차 갱신을 직접 확인했다. 본 검토에서는 그 전체 조류 원자료·허용 alias·식별자·이용허락을 확보/검증하지 않았다. 따라서 19종+본 normal fixture에 쓰인 검증 명칭의 최소 사전은 **분석용 사전**, 전체 운영 사전 완성품이 아니다.

운영 사전 확정 시 source URL/발표일/목록 기준일/입수일/파일 SHA256/종명별 source identifier/alias 근거와 승인자/이용허락을 고정한다. 외부 사이트 runtime 장애가 보호 판정을 allow로 전환해서는 안 된다. 판정 룰과 사전 버전은 분리한다. 옛 전자책의 제목/본문 라우팅 불일치나 구 PDF의 HTML fallback 응답을 최신 명칭 전체의 증거로 채택하지 않는다.
