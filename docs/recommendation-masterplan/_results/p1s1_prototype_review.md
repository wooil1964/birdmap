# P1-S1 prospective prototype 독립 대조

범위: 다른 agent의 standalone 44-case prototype 함수를 읽어 독립 groundtruth 70개와 추가 경계 14개에 적용했다. 운영 코드, 분석 worktree 및 다른 agent 파일은 수정하지 않았다. 결과에 prototype SHA256을 기록했다. 보호 정책의 생태학적 정답이나 실서비스 오탐률을 평가한 실험은 아니다.

## 정상 입력 분모 17개

| 조건 | 독립 결과 |
|---|---:|
| S1-R (현행19종 표기 방어) 보호 오탐 | 0/17 |
| S1-P 정상 정확위치/가점 공개 유지 | 5/17 |
| S1-P 정상 입력 보류 | 12/17 |
| 최소 사전에 정상 이름이 없어 unresolved로 보류 | 11/17 |
| 명칭은 resolved지만 알 자연어 규칙 때문에 보류 | 1/17 |

S1-P의 12개 보류를 S1-R 보호종 오탐 12개라고 합치면 잘못된 해석이다. 다만 실제 정상 공개 호환성을 평가할 때는 coverage누락 11개도 보류 비용에 포함해야 하며 별도 분모·원인으로 보고한다. 동박새/한국동박새/갈매기류/알락오리 등 원문이 알려진 정상 종명은 최소5개 테스트 registry에 빠져 있다. 해당 사전으로 운영 전체 호환성이 확보됐다고 승인할 수 없다.

## 수량과 괄호 경계

독립 실행 시점의 **갱신된 prototype**은 `울새0`·`울새100001`을 ambiguous_count→withheld, `울새100000`을 known_count→allow로 처리했다. 직전 읽은 버전에서는 Number.isSafeInteger만 적용됐지만, 그 지적은 실행 전에 이미 반영됐다. 최종 문서에는 갱신본 SHA/결과를 기준으로 기록해야 한다.

- 음수·소수·지수 표현은 unresolved→withheld이며 원문을 지우거나 임의 수량으로 변환하지 않는다.
- `울새 (1)`·`울새 (1마리)`는 현재 unresolved→withheld이다. 괄호 수량을 정상 허용할지의 **입력 문법 승인 선택**이 필요하다. 허용한다면 정확한 등록 종명 + 괄호 안 정수/단위 전체 일치만 지원하고 1~100000 경계·상한 초과·미완성 괄호·중첩 괄호·종명 안 괄호를 별도 검증한다. 불명확한 문자열에서 괄호/숫자를 일괄 삭제하지 않는다.
- `울새01`은 count1로 처리되므로 leading-zero 허용 여부와 원문 보존을 명시해야 한다. 이는 문자 수량 표현의 파싱이며 실제 관찰 개체수의 검증이 아니다.
- 행 전체 birdCount 입력 검증과 종별 문자열 접미 수량은 서로 다른 필드 계약이다.

## 알 문맥: prospective 규칙 보완 필요

| 합성 note | prototype 결과 | 설계 요구 |
|---|---|---|
| 날씨를 알 수 없음 | 알 단독 regex 때문에 withheld | 비번식 정상 문맥을 단순 알 단어만으로 차단하지 않음 |
| 알을 품고 있음 | allow | 번식/민감 문맥으로 withheld |
| 알이 있음 | allow | 번식/민감 문맥으로 withheld |
| 알 2개 확인 | withheld | 유지 |
| 알락할미새 관찰 | allow | 유지 |

이것은 **새 알 정책 prototype의 누락·오탐**이며 현행 6개 키워드 보호나 S1-R 표기 방어의 회귀가 아니다. 알의 단독 경계만으로 한국어 의미를 확정할 수 없다. 조사형(`알을`/`알이` 등), 수량 단위, 부화/포란 문맥, '알 수 있음/없음' 같은 일반 문맥과 모호한 문장을 함께 테스트해야 한다. 특정 표현을 제외하는 regex도 `알 수는 2개` 같은 실제 알 개수 문맥을 놓칠 수 있으므로, 광범위한 동의어/형태소 처리를 검증한 것처럼 표현하지 않는다. 불확실성을 정확위치 공개로 해소하지 않고 review로 남기는 정책을 명세한다.

## 승인 조건

1. S1-R 현행19종 표현 방어와 S1-P 공개정책 변경을 분리한다.
2. 완전한 공식 조류 사전·alias·식별자·이용허락은 본 조사에서 확보하지 않았다. 최소 fixture registry를 production 사전으로 쓰지 않는다.
3. 독립 정상17개와 추가수량/알/괄호 반례를 회귀 명세에 포함한다. 검은머리갈매기·새매 등 현행19미포함/공식 보호 검토군을 일반종 오탐 분모로 합치지 않는다.
4. 정책P는 위 사전 coverage, 알 문맥, 괄호 문법을 검토·승인하기 전 운영 적용 완료로 보고하지 않는다.
