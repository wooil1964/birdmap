# 섬 탐조 맛집·숙박 검색 시범

최신 main `e7dbdc8079d0d4d435a4d9a8fd2553b751860822`에서 분리한 검토 브랜치입니다. 운영 OSM 지도와 배포 보류 중인 [VWorld 초안 PR #40](https://github.com/wooil1964/birdmap/pull/40)을 변경하거나 배포하지 않습니다.

## 최소 변경 설계

공통 탐조지 팝업 `v23PopupContent`에 기본 접힘 상태의 ‘주변 맛집·숙박 검색’ 한 칸을 추가합니다. PC·모바일에 같은 경로를 사용하며 기존 지도 버튼 행과 여객선 정보·KSA 링크를 그대로 유지합니다. 링크는 지도 서비스의 검색 화면을 새 창으로 엽니다. 검색어는 행정구역·섬 이름·음식점/숙박을 조합합니다. 거리순·반경 검색이나 추천 업체 목록이 아니므로 실제 위치를 확인하도록 안내합니다.

| 섬 | 기존 마커 ID | 검색 기준 |
|---|---|---|
| 어청도 | 1, 101, 102, 103 | 전북 군산 어청도 |
| 외연도 | 2, 104, 105, 106 | 충남 보령 외연도 |
| 흑산도 | 63, 127, 128, 129, 130 | 전남 신안 흑산도 |
| 백령도 | 4, 117, 118, 119 | 인천 옹진 백령도 |
| 소청도 | 110, 111 | 인천 옹진 소청도 |
| 홍도 | 64 | 전남 신안 홍도 |

6개 섬의 기존 20개 마커에만 표시합니다. 소청도는 예동마을·등대 두 지점입니다. 전국 229개 탐조지의 데이터·좌표·기상 서버 등록정보·엑셀·조석 매핑은 변경하지 않습니다. API 요청, 업체명·주소·사진·리뷰·평점·가격 복제, 저장, 위치 권한 요청은 추가하지 않습니다. 숙박 가능 여부와 예약은 업체의 공식 예약처에서, 여객선 운항과 예약 가능 여부는 기존 KSA·선사에서 출발 전에 확인하도록 안내합니다.

`index.html` 변경은 CSS·정적 설정/도움 함수·팝업 연결을 합쳐 42줄 추가뿐입니다. 나머지 파일은 검사·검토 문서입니다. 기존 전체 HTML 보존 검사는 새 추가 영역의 정확한 해시와 단일 연결 구문만 제외하며 변경·중복·누락·범위 밖 삽입을 계속 거부합니다. PR #40의 바탕지도 보존 검사와 함께 사용할 수 있습니다.

- Python 시범·보존·제주·수도권·중부·등록 검사 29/29. 조석 검사 21개 통과, 기존 조건부 검사 1개 생략. SEO 페이지 194개 동기화 확인.
- 실제 Chrome 320·344·375·768·1024·1440px에서 25/25. 전체 229개 실제 마커와 비시범 팝업 경계, 20개 시범 팝업의 링크, 네이티브 펼치기·Enter 접기, 44px 터치 영역, 가로 넘침, 기상 갱신 후 펼침 유지, 검색·이번 주 추천·월간 조석·제보 열기/취소 확인.
- 새 검색 링크 4개와 기존 네이버·카카오·티맵·Windy·KSA 5개가 스크롤 후 실제 포인터 위치에서 접근 가능함을 확인.
- 브라우저 검증은 기상·제보 서버를 합성 응답으로 대체하고 외부 비GET을 차단합니다. 운영 요청·외부 비GET·제보 제출 0건. 공개 OSM 타일은 로컬 검증에서만 읽으며 CI에서는 타일 요청을 끕니다.

처음 제한 환경에서 발생한 20개 실패는 변경 전 main에서도 동일하게 재현됐습니다. Leaflet CDN 접근이 막힌 환경의 초기화 오류 19개와 Python 한글 출력 인코딩 1개였습니다. 정상 네트워크와 기존 CI의 UTF-8 설정으로 전체 444개가 통과했습니다.

실제 휴대전화, 설치된 지도 앱 실행, 외부 검색결과의 지역 정확도, 업체 영업·객실·배편 가용성은 검증하지 않았습니다. 검색 링크의 목적지·검색어는 검사했으며 업체 검색결과 페이지는 수집하거나 열지 않았습니다.

## 공식 연결 근거와 API 후속 검토

- 카카오 검색 URL `https://map.kakao.com/link/search/{검색어}`는 [카카오 공식 Web 가이드](https://apis.map.kakao.com/web/guide/#routeurl)의 지도 검색결과 바로가기 형식을 사용합니다.
- 네이버 웹 검색 `https://map.naver.com/p/search/{검색어}`는 [네이버 웨일 담당자 안내](https://forum.whale.naver.com/topic/57381/)로 확인했습니다. 별도 안정성이 보장된 API 계약이 아니므로 서비스 경로가 바뀌면 재확인이 필요합니다.
- 카카오 [Local API](https://developers.kakao.com/docs/ko/local/dev-guide)는 좌표·반경과 음식점 FD6/숙박 AD5 분류를 지원하므로 후속 실시간 검색 후보입니다. [공식 저장 정책 답변](https://devtalk.kakao.com/t/api-id/152228)에 따른 주소·좌표 저장 제한 및 장소 ID·URL 활용 범위를 확인해야 합니다. [타사 지도 관련 답변](https://devtalk.kakao.com/t/local-api/151190/2)을 보면 기본 지도를 바꾸지 않고 검토할 수 있습니다.
- 네이버 신규 검색 API 연동은 [공식 API HUB 이관 공지](https://developers.naver.com/notice/article/32530)에 따라 API HUB를 기준으로 확인합니다. 기존 Developers 신규 신청은 2026-07-31 차단됐고 기존 이용자의 지원 종료는 2027-06-30입니다. [현행 Developers 약관](https://developers.naver.com/products/terms/)과 API HUB의 적용 약관·출처 표시·캐시·별도 DB 제한·요금·쿼터를 연동 직전에 다시 확인해야 합니다.

후속 API는 별도 승인 범위로 진행합니다. 키를 브라우저에 하드코딩하지 않고 서버 경유·호출량 제한·실패 시 현재 검색 링크 복귀를 검토합니다. 예약·잔여 객실·운항 상태를 확정하려면 해당 공식 제공처와의 별도 연동이 필요합니다.
