# 풍향·풍속·강우 개선안

## 공통 계산 계약

기상 풍향φ는 불어오는 방향(FROM)이다. 동향u=−S·sinφ, 북향v=−S·cosφ. 진북 기준 이동방향H의 순풍은u·sinH+v·cosH, 측풍은u·cosH−v·sinH다. 단위는m/s이며 점수나 확률이 아니다.
실제 경로·종·고도가 없으면H를 확정하지 않는다. 봄 북향/가을 남향은 가설이며 우회 이동종에는 맞지 않을 수 있다. 0/90/180/270°를 병렬 비교하고, 최대 순풍값을 골라 모든 바람을 유리하다고 판정하지 않는다. 각도 산술평균 대신 벡터/원형 통계를 쓴다.

## M1 — 현행 추천 유지, 풍벡터 설명

우선순위1. 현재 주간 표본으로 풍속·풍향의 벡터와 가설 이동축별 순풍/측풍을 연구용 설명에 표시한다. 이동축 미확인→이동지원 미확인, 고층풍 미확인→지표10m 진단이라고 명시한다. 관측이력이 충족될 때만24/48시간 방향 지속성·역전·평균 성분을 계산한다. 현재는 미확인이다.
근거는 Bozó/Gill/Nourani/Nussbaumer의 계절·경로·고도 차이다. 기대 효과는 현행 풍향 가점의 한계를 설명하고 검증할 변수를 확보하는 것이다. 일반 추천의 점수·rank·정원·B·날짜는 유지한다. 점수 분포가 그대로인 결과를 생태 정확도 개선으로 주장하지 않는다.
현재174개 후보의 벡터 계산과 단위/반증 검사가 가능하다. 실제 비행고도 지원, 과거48시간 추세, 현지 출현 증가는 검증할 수 없다. 기존 도서+8점을 즉시 삭제하거나 대체하는 정책은 이번 설계의 적용 범위가 아니다.

## M2 — 출발·통과·체류 및 특별 기상 이슈 분리

우선순위2. 먼저 offline shadow로 비교한다. 일반 추천과 별도 채널에서 기상조건, 이동 가설, 실제 공개 승인 관찰을 각각 표시한다. 출발 증가를 같은 기착지의 관찰 증가로 바꾸지 않는다. 악천후 착지와 비 종료 후 이동 재개는 현지 체류에 반대 영향을 줄 수 있다.
변수는 실제24/48시간 바람·기압/전선·강수 구간·상류 경로·종/길드·연령·고도다. 24/48시간은 비교 창이며 검증된 생태 임계값이 아니다. 3시간 누계로 정확한 강수 종료를 만들지 않는다. 실제 사건에 연결된 종별 관찰이 없으면 기상 가설로만 표시한다.
Rüppel/Cooper/활공종 기착 및 태풍 연구가 근거다. 기대 효과는 검증 가능한 이슈와 안전 차단을 명확히 분리하는 것이다. 공식 특보·너울·접근 허용, 관측 이력과 관찰 정답이 필요하다. 현재 입력의 장소이슈0은 자료 부족 결과이며 새가 없다는 뜻이 아니다. 일반 점수에 가산하지 않는다.

## M3 — 관측 노력·검출 보정 모형

우선순위3. 출발, 통과량, 착지/체류, 현장 검출을 별도의 목표변수로 학습한다. 계절·서식환경·지역·관찰노력을 구분하고 실제고도풍·기압·전선·조석·먹이/수위·결빙 등을 필요한 범위에서 추가한다.
Johnston/Horton의 검증 방법과 물새·맹금·산림의 다른 기작이 근거다. 완전 체크리스트, 시간/거리/인원, 비검출, 종별 날짜 및 반복 관찰의 독립성 정보가 필요하다. 현재 성공 제보만으로 새 점수나 출현 확률을 학습하지 않는다.
봄·가을 전향적 조사→연도/지역 보류 검증→실제 예보로 검증→확률 보정 순서를 권고한다. 기간은 표본 충분성 보장이 아니며 희귀 사건 빈도에 따라 추가 자료가 필요하다. 순위 변화나 점수 분산 증가 자체를 개선으로 보지 않는다. 이 안의 신규 점수·순위·예측 성능은 미실행이다.

## 데이터·운영 비용

M1은 기존JSON 재사용시 추가 상류요청/D1/권한 폴링0으로 설계 가능하다. 174×4=696회 투영, 전체 주간은42560회다. 이는 연산수이며 실제 CPU 밀리초는 미계측이다.
M2는 관측소·격자를 공유하는 발행단위 배치와 파일 캐시가 적합하다. 190×24h=4560지점시간/일,48시간9120개,3고도라면13680지점-고도-시간/일이다. 해안5~7곳의72시간은360~504개다. 논리 레코드수이며 API 호출/D1 청구량이 아니다. 공유 매핑은 미완료다.
M3는 현장 조사·품질관리·학습 비용이 가장 크다. KMA 인증·할당량, 상용 기상계약, 저장/CPU 비용을 실제 확인하지 않아 월요금은 산정하지 않았다. 사용자별190조회나 공개D1 전수조회를 추가하는 설계는 권고하지 않는다. 기존5초 공개권한 계약은 이 연구에서 최적화하지 않는다.

## 구현 순서와 승인

M1의 연구필드/문구/QC와 수집 범위를 먼저 승인받는다. 관측 이력·공식 위험자료 매핑과 결측/지연 정책 검증 후 M2 shadow를 진행한다. M3는 노력량·비관찰 자료 및 독립 검증 뒤에만 배점 정책을 검토한다. 운영 점수나 특별 장소 안내는 이번 연구 완료만으로 적용하지 않는다.
