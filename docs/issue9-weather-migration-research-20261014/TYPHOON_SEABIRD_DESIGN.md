# 일본 태풍·동해안 바닷새 특별 이슈 설계

## 사실과 가설

일본 주변 태풍과 한국 남동해안 바닷새 관찰의 시간적 연관성이 확인됐다. 슴새 성체 추적은 측풍과 육지의 상대 위치에 따른 능동회피 및 태풍 눈 방향 이동을 보여 준다. 모든 바닷새가 수동으로 떠밀려 한국에 나온다는 일반 규칙은 지지하지 않는다. 종·연령·비행형태·상대 위치를 구분해야 한다. RESEARCH_SOURCES.md에 원논문과 한계를 정리했다.

## 사후 부분 재현

JMA 공식 best-track ZIP의 SHA256은 `76b65a4210e0a9f69c6ce56b401ac572d4203c11edf1f30691a20a891353cef6`다. Halong91행/Goni82행 총173행을 고정했다. UTC/KST의 절대시각 일치173건과 인접171시간쌍의 단조 증가에 오류0이었다. JMA PDF 일본시와 KST는 모두+09:00이다.
Halong의9~10일 KST 구간은17행(TY14/STS3)이다. 구룡포10일07:30~13:30 전체 관찰범위 안의09/10/12시 진로는TY였다. Goni25~26일은14행이며25일21시 KST에 온대저기압으로 바뀐 뒤26일 관찰이 이어졌다. 태풍 소멸을 너울이나 이동 영향 소멸로 해석하면 안 된다.
`maxWindKt=0`은 최대풍속 미제공으로 처리한다. 특히 온대저기압의0을 해안 무풍으로 해석하지 않는다. 원 인코딩은JMA_CASE_TRACKS.json, 수정 해석은VERIFIED파일에 분리 보존했다.
CASE_REPLAY는 기존 공개 정적지점의 태풍중심 거리만 계산한다. 국지 바람·파랑·노력량·대조일 정답이 없어 **사건 연계 부분 재현 PASS**, 완전한 생태 hindcast·오탐/미탐률·24/48/72시간 관찰 가능 기간은 **미실행**이다. 태풍중심에서 국지 바람장을 만들어내지 않았다.

## 연구 입력과 공간 조건

일본 서쪽·동쪽·남쪽이라는 구분만으로 동해안 풍향을 확정하지 않는다. 실제 태풍중심의 상대 위치, 이동벡터·속도, 진행방향 기준 전면/후면, 최근24/48시간 바람·기압·강우, 파향·주기·너울을 함께 분석한다. 상층 이동풍과10m 해상풍을 분리한다.
FROM을TO벡터로 바꾼 뒤 확인된 연안 법선/평행 방향에 투영한다. 해안 방향 미확인→성분 미확인이다. 대략 서향 법선을 모든 동해안에 넣지 않는다. 북반구 반시계 도식은 방향 계산의 합성 시험에만 사용한다.
사건 후24/48/72시간은 비교 자료창이며 종별 관찰기간이나 안전 해제시간이 아니다. 온대저기압 전환 이후도 너울을 검사한다.

## 기존 등록지점 검토

기존 registry에서 ID49호미곶,53주문진항,54어달항,188이천항,189도구해수욕장,190임곡항,191강사리선상탐조의 해안/외해 환경과 규칙군을 대조했다. 원본 좌표·pelagic flag·분류를 바꾸지 않았다.
현장 시야, 공식 접근 허용, 월파 노출, 해안 방향, 관측 격자·너울지점 매핑은 미검증이다. 따라서7곳을 특별 탐조 운영 후보로 확정하지 않는다. KMA2024자료의 도구해수욕장 예측지점 제외 기록은 현재 공식 매핑을 다시 확인해야 할 근거다. 구룡포 한 지점의 정보를 주변 모든 곳의 안전으로 확대하지 않는다. 신규 지점을 만들지 않는다.

## 이슈·안전·위치 계약

별도 필드는 기상사건(출처/발행/유효기간), 바람근거(관측/예보/가설), 이동가설(종/길드/경로/한계), 공개관찰(사건과 연계한 승인 사실), 안전상태, 위치권한이다. 일반 추천 점수와 무조건 합산하지 않는다. 현재 최근 종수 집계는 특정 태풍 희귀종의 확정 출현 근거로 승격하지 않는다.
특별 장소 안내는 **사건 확인 + 현재 위치권한 + P0 안전 + 최신 공식 특보 + 너울 확인 + 접근 허용**을 모두 충족할 때만 검토한다. 위험이나 자료부족·지연·매핑불명에서는 장소·정확위치·길찾기를 제공하지 않고 문헌/기상 설명만 남긴다.
[KMA 원본 PDF](https://www.kma.go.kr/kma/servlet/NeoboardProcess?bid=press&callback=https%3A%2F%2Fwww.kma.go.kr%2Fkma%2Fnews%2Fpress.jsp&fno=3&k=ATC202409301131103_c1d01938-f97b-40f9-82d5-c6895cbb5556.pdf&mode=download&num=1194409&ses=USERSESSION)는 해안 약풍에도 먼 해역 너울이 위험할 수 있다고 설명한다. 특보 미발효·현지 약풍·3시간 비0·태풍 소멸·기존 safe=true는 해안 안전 보증이 아니다.
P0 강수1mm·만조90분·선상풍속≤6m/s/파고≤0.7m/강수0을 유지한다. 보호종/번식/동의/epoch-revision/nonce/fresh postflight/CAS/terminal/5초 만료/숨김/GPS 재확인을 유지한다. 논문 번식지·개체추적 정확좌표를 재게시하지 않는다.

## 검증 계획·오탐·비용

오탐 가설은 경로/고도 차이·능동 회피·야간 통과·노력/시정 편향·너울 위험 누락이다. 미탐 가설은 측풍 활공·먹이·지연 체류를 놓치는 경우다. 현재 자료로 각각의 비율을 산출하지 않는다.
공식 진로+부이/기압/파주기+사건/대조일 완전목록을UTC로 연결하고 시간순/지역 보류 검증을 해야 한다. 공식 안전 판단은 생태 성능과 독립 감사한다. 관측 없는 지점의 종 목록 생성은 금지한다.
운영비용은 공통 관측·위험자료 배치, 품질관리 및 사건별 검토가 추가된다. API 할당량·CPU·월요금은 미계측이다. 기존 공개권한Worker/D1에 새 추적자료를 넣거나 사용자별 전수 조회를 추가하지 않는다.
