# Issue #21 — 최종 판정: DEPLOYED

제보자 닉네임을 누르면 **누적 출현종 수·승인 제보 건수**를 표시하는 기능을 운영에 반영했습니다. 이미 공개된 닉네임만 사용하며, 같은 닉네임은 합산될 수 있다는 안내를 표시합니다.

## 집계와 개인정보 계약

`status='approved' AND name_public=1 AND reporter IS NOT NULL AND TRIM(reporter)<>''` 행만 집계합니다. 닉네임은 원문이 정확히 일치해야 합니다. 건수는 행 수, 종수는 기존 `splitSpecies(' · ')` 결과의 서로 다른 종명 문자열 수입니다. 분류학적 동일성이나 회원 ID를 추정하지 않습니다.

현재 공개 이력 ID 또는 월간 기여자 출처를 같은 primary D1 batch에서 확인합니다. 통계 응답과 팝업에는 두 숫자만 들어가고, API에는 P1 nonce/epoch/revision·serverTime 메타데이터만 추가됩니다. 이름·종 목록·좌표·개별 ID·관찰일·메모는 통계 응답에 없습니다. 없는 이름과 비공개 이름은 동일한 미확인 응답을 받습니다. 공개 출처 witness는 비밀 인증 토큰이 아닙니다. 새로운 전체 닉네임 검색 API나 분산 rate limit을 구현했다고 주장하지 않습니다.
