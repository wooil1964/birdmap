# PC GPS 안내 중 상세 팝업 이름표 축소 — Claude Code 작업 보고

- 작업 도구: Claude Code (단독)
- 기준 커밋: main `afe6fb9` (PR #55 병합)
- 작업 브랜치: `fix/gps-pc-popup-nametag-20261029`

## 1. 작업 목적
PC에서 탐조지·출현종 상세 팝업의 **내 위치 찾기** 성공 뒤 큰 흰 팝업이 GPS 파란 점·점선 안내선·직선거리를 가리는 문제를 해결한다. 팝업은 열린 채(공개 목적지 검증·마커 연결 유지) 작은 이름표로만 줄인다.

## 2. 원인 (확정)
- PR #54/#55의 접기는 모바일 미디어 조건에서만 동작한다(`birdmapCollapseMobilePopupForGps`, `birdmapCollapseReportLocationForGps` 모두 PC에서 `false`). PC 팝업은 설계상 그대로 남았다.
- `fit()`은 팝업 높이만큼 위쪽 여백을 두지만, 사용자가 목적지 북쪽(팝업 높이 이내)에 있으면 팝업이 파란 점·거리 라벨을 덮는다(PR #55 보고서 6항, 1440×1000 합성 측정).
- 같은 마커를 다시 누르면 Leaflet 기본 동작(`_openPopup` → `closePopup`)이 팝업을 닫아 `popupclose`로 안내가 끝난다.

## 3. 구현 방식
- `assets/birdmap-location.js`
  - `create()`: 접기 콜백에 검증된 목적지(`target`)를 함께 넘긴다(`draw`, `focusGuide`). 새 GPS·공개 요청 없음.
  - `install()` PC 분기: `tag()`가 팝업에 `birdmap-gps-tag` 클래스와 이름표 버튼을 붙이고 `options.offset`을 임시로 바꿔 위치를 잡는다. 원래 `offset` 디스크립터는 저장 후 정확히 복원한다. `map.closePopup()`을 쓰지 않는다.
  - 이름: 탐조지 `siteData.name`, 고정 붉은 점 `siteSpotData.species`, 제보는 `/reports/search` 정확한 ID 검증 행의 `species`(`publicReportGuideTarget`). 임의 종명 없음, `textContent`만 사용.
  - `placeTag()`: 이름표를 마커 위·아래·오른쪽·왼쪽 후보 중 안내선(표본 41점)·거리 라벨·파란 점과 겹치지 않고 지도 안에 들어가는 첫 위치에 둔다. 기존 GPS 도구 배치(`place()`) 앞에서 호출되어 줌·이동·크기 변화 때 다시 계산한다.
  - 문서 캡처 단계 `click`/`keypress(Enter)` 한 개: 안내 중 같은 마커 또는 이름표를 누르면 Leaflet 토글을 막고, 이름표 상태면 펼치기, 펼친 상태면 `focusGuide()`로 다시 이름표+시야 맞춤. 리스너는 설치 시 한 번만 등록된다.
  - `fit()`: 이름표 상태에서도 펼친 팝업 크기로 여백을 잡아, 펼치거나 안내를 끝내도 기존 배치(필터 패널·GPS 도구 비가림)를 유지한다.
  - Leaflet `update()`는 문자열 팝업 내용을 다시 만들기 때문에 이름표 전환은 `_updateLayout`/`_updatePosition`만 호출한다(Leaflet 1.9.3 고정).
  - 모바일로 화면이 바뀌면 이름표를 즉시 해제한다. 모바일 코드 경로(PR #55 56px 막대, 64px 시트)는 그대로다.
- `assets/birdmap-species-search.js`: 검증 목적지에 종명 추가. 이름표 상태에서 최근 15건·종명 링크로 같은 제보를 다시 누르면 카드를 새로 열지 않고 펼친다(안내 유지).
- `assets/birdmap-location.css`: 이름표 스타일(최대 220px, 말줄임, 포커스 표시). 이름표 상태에서만 본문·꼬리·닫기 버튼을 숨긴다.

## 5. 좌표 검증
좌표·`siteData`·`sites.js`를 수정하지 않았다. 시험에서 탐조지 229곳과 목적지 마커 좌표 = 공개 정본 일치가 유지됐다.

## 6. 남은 위험
- 실제 PC 브라우저·마우스·실제 GPS(노트북 Wi-Fi 위치)로는 확인하지 않았다(합성 GPS).
- 이름표가 들어갈 네 방향이 모두 막히면(극단적으로 작은 지도) 가장 덜 겹치는 위치를 쓴다.
