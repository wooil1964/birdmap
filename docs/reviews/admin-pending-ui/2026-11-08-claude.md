# 관리자 화면: 승인 전 공개 버튼·문구 정리 (2026-11-08, Claude)

## 1. 작업 목적

PR #78 운영 반영 뒤 승인 전 제보는 지도에 공개되지 않는다. 그런데 관리자 화면에는 예전 "황색 마커" 버튼과 문구가 남아 있었다. 이를 현재 정책에 맞게 정리한다. 관리자 화면 표시만 바꾸며, API·D1·공개 Worker는 변경하지 않는다.

## 3. 변경 내용

| 항목 | 수정 전 | 수정 후 |
|---|---|---|
| 카드 상태 배지 | 원문 `pending` / `approved` / `rejected` | `승인 대기 · 지도 비공개` / `승인 완료` / `반려` (실제 상태값은 그대로) |
| 대기 카드 부가 배지 | `pending_public` 값에 따라 `황색 마커 공개 중` 또는 `공개 보류` | 삭제 |
| 대기 카드 버튼 | `황색 마커로 공개` / `황색 마커 내리기` | 삭제 (클릭 처리 코드와 결과 문구도 함께 삭제) |

유지한 기능: 목록·상태 탭, 종명·관찰일·좌표 수정 후 승인, 반려, 공개 취소, 반려 후 재승인, 선택 지점 연결·해제, 위치 가리기·해제, 탐조 지역 저장, 이름 공개 반영, 관리자 메모, 이력·통계 화면.

관리자 API의 `visibility` 동작은 서버에 그대로 남는다(API 무변경). `public=true`는 PR #78 이후 서버가 400으로 거절한다.

## 5. 보안·기존 기능 영향

공개 Worker, 공개 API, 보호종 위치 정책 v2, D1 구조와 데이터, `index.html`(사용자 지도)은 변경하지 않았다. 관리자 Worker에 반영하기 전까지 운영 관리자 화면은 그대로다.

## 6. 남은 사항

- 운영 반영은 관리자 Worker(`birdmap-reports-admin`) 배포가 필요하다(별도 승인).
- 카드의 `위치 공개: 공개` 줄은 "위치 가리기 여부"를 뜻하는 기존 문구다. 대기 제보에서는 "승인 후 공개 방식"으로 읽어야 한다. 이번에는 바꾸지 않았다.
- 위치 가리기 해제 확인창의 "실제 관찰 좌표가 공개 지도에 표시됩니다"도 대기 제보라면 승인 후의 일이다. 기존 문구 그대로 두었다.
