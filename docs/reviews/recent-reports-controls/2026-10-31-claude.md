## 1. 사전 확인

- `AGENTS.md`는 저장소에 없다(루트·하위 검색). `CLAUDE.md`·`AI_WORK_RULES.md`를 따랐다.
- PR #58은 제목줄 안내문(`당신의 제보가 지도가 됩니다!`)과 PC 상자 폭 360px만 바꿨다. index.html 고정 검사 예외로 들어가 있다.
- 기존 접기/펼치기·닫기·`최근 제보` 다시 열기는 `assets/birdmap-basemap-init.js`의 **모바일 시트 전용** 구현이다. 버튼(`⌃/⌄`, `×`, `#birdmapRecentReopen`)은 PC에서도 DOM에 있지만 CSS로 숨겨져 있었다.
- 중복 구현을 피하려고 **같은 버튼 세 개와 같은 함수**를 PC에서도 쓰고, 상태만 PC용으로 따로 둔다.

## 2. PC 최근 제보 상자 동작 (900px 이상, 모바일 배치가 아닐 때)

| 조작 | 결과 |
|------|------|
| 기본 | 상자 열림. 제목줄 오른쪽 위에 `−`(줄이기)·`×`(닫기) 28px 버튼 |
| `−` | 제목줄만 남김(건수·안내문·힌트 유지). 탭·목록·기여자·`전체 보기` 숨김. 상자 아래 끝 위치 그대로. 버튼이 `+`(펼치기)로 바뀜 |
| `+` | 원래 크기로 펼침 |
| `×` | 상자 숨김. 같은 모서리(오른쪽 30px·아래 60px)에 작은 `최근 제보` 버튼이 나타나고 초점이 그 버튼으로 감 |
| `최근 제보` | 닫기 직전 상태(열림 또는 줄임)로 되돌리고 초점은 `−/+`로 감 |

- 접근성 이름: `최근 제보 줄이기` / `최근 제보 펼치기`(aria-expanded 함께 바뀜), `최근 제보 패널 닫기`, `최근 출현 제보 패널 열기`. 마우스용 `title`도 붙였다.
- 키보드: Enter·Space로 줄이기/펼치기, Tab으로 `×` 이동, Enter로 닫기·다시 열기.
- 상태는 페이지마다 새로 시작(PC는 열림). 저장하지 않는다.
- 모바일 시트 상태와 PC 상태는 **따로** 둔다. PC에서 닫고 창을 휴대폰 폭으로 줄이면 모바일 시트는 원래 상태로 보이고, 다시 넓히면 PC는 닫힌 상태가 유지된다.
- 오른쪽 패널(`rightPanelOpen`)·제보 위치 선택(`reportPicking`) 중에는 상자처럼 `최근 제보` 버튼도 숨는다.
- 701~899px(기존 166px 축소형 상자)는 바꾸지 않았다. 버튼이 없고 이전과 같다.
