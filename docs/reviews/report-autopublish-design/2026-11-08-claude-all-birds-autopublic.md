# 전체 조류·미조 자동 공개 개편 (로컬 구현·검증)

- 브랜치: claude/all-birds-autopublic-20261108 (기준 ba7a1e8). 로컬 전용: push·PR·CI·배포·운영 D1 변경 없음. 자동 공개 스위치 2개 OFF 유지.

## 1. 자동 공개 판정 방식
- 종 이름 허용 목록(15종)과 보호종·희귀종·위치 민감종 보류를 폐지했다. 이름이 **식별 가능**하면 종류와 무관하게 공개한다.
- 식별: 공식 국명(2025 목록), 학명·영명(KOS 대응표 598건, `official-bird-aliases.js`), 목록 밖의 학명 꼴(`Genus species[ subspecies]`)은 `scientific_unlisted`로 통과. 원문은 그대로 보존하며 "국내 미기록"으로 확정·표시하지 않는다.
- 여전히 검토로 보내는 경우: 식별 불가 이름(목록 밖 영명·모르는 한글), 불확실 표기(sp., cf., aff., 또는, 같음 등), 수량 이상, 오래된 관찰, 동일일·동종·200 m 이내 중복, 하루 한도, 번식 표현은 접수 단계에서 400.
- 같은 종은 국명·학명·영명이 달라도 동일 종으로 보아 200 m 중복을 판정(D1 `autodup` 단언으로 동시 접수도 1건).

## 2. 미조 입력 처리
- 목록 밖 학명 꼴은 자동 공개, 목록 밖 영명·알 수 없는 한글명은 `name_unconfirmed`로 관리자 검토. 종명 길이 상한 40자(영명 33자 허용), 형식 검사는 유지.

## 3. 기존 보호 정책(v2)과의 관계
- v2(19종)는 변경하지 않았다. 위치 가림은 제보자 선택 그대로(대략점 1.5~4.5 km, 실제 좌표는 공개 응답 어디에도 없음).
- **영향**: v2 19종을 가리지 않고 제보하면 종명만으로는 더 이상 보류되지 않고, v2가 승인 후 공개에 허용하는 범위(비번식 확인)와 같은 좌표로 즉시 공개된다. 이전 방식은 보호종 사전 검토였으므로 정책 의도와 충돌할 수 있어 운영 전 확인이 필요하다. 번식·둥지 입력 차단과 편집 행의 v2 백스톱은 유지.
