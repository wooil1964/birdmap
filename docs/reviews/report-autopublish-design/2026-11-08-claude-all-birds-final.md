## 1. 2025 목록 밖 학명: 국제 분류목록(IOC) 대조
- 자료: IOC World Bird List v15.2 (worldbirdnames.org, doi 10.14344/IOC.ML.15.2, 라이선스 CC BY 4.0). 속 2389, 현존 종 11,064(멸종종 제외), 영명 11,064. `reports-api/src/ioc-taxa.js`(생성 파일, 589 KB), 생성기 `docs/report-autopublish-20261108/gen-ioc-taxa.py`.
- 판정(이름 해석 `identifyBird`):
  1. 한국조류학회 2025 국명·학명·영명 → 기존대로.
  2. IOC 영명 또는 IOC 학명(속+종소명, 아종 허용) → `ioc_english`/`ioc_scientific`: 실존 종으로 확인, 자동 공개.
  3. 속은 IOC에 있으나 종소명이 없음 → `scientific_genus_only`: 오기·신종·분류 변경일 수 있어 **확정하지 않고** 원문 그대로 공개(미조 신속 공개 보장), 관리자 화면에 기존 "공식 국명 확인 필요" 표시(공개 화면 변화 없음).
  4. 속명도 IOC에 없는 라틴어 꼴, IOC에 없는 영명 → 식별 불가, 관리자 검토(`name_unconfirmed`).
- 한국 목록과 IOC의 학명 차이(예: Charadrius dubius ↔ Thinornis dubius)는 영명으로 이어 같은 종으로 취급, 두 학명 모두 중복 비교 별칭으로 둔다. 598종 중 차이 4종(3종은 영명으로 연결, 1종은 멸종종).
- 남은 위험: 3번(속만 맞는 가짜 종소명)은 공개된다. 선택지는 이 경우도 검토로 돌리는 것(미조 신종·분류 변경 지연). 현재는 공개 우선.

## 2. 위치 정책 v2 19종: 실제 좌표 노출 범위 조사 (정책 변경 없음)
- 접수 시 "비번식 확인"(non_breeding_confirmed)은 필수(없으면 400). 번식·둥지 표현은 400.
- 실측(실제 D1, 19종 × 가림/가리지 않음 = 38건): 가리지 않은 19건은 **`/reports/pending`(자동 공개 목록)에만** 실제 좌표(소수 5~6자리)가 나가고, approved·검색·최근 장소·기여자 응답에는 없음. 가린 19건은 어떤 공개 응답에도 실제 좌표가 없고 대략점(1.5~4.5 km 이동)으로만 표시.
- 발견·수정: v2 판정이 국명만 비교해서, 확인이 없는 행(관리자 편집·과거 행)에 학명·영명(예: Platalea minor)을 쓰면 보호되지 않던 틈이 있었다. 이름 해석만 넓혀 같은 19종을 학명·영명으로 써도 보호하도록 고쳤다(목록·정책은 그대로 19종).
- 운영자가 결정할 사항:
  1. 19종을 가리지 않고 제보하면 사람의 검토 없이 즉시 실제 좌표 공개(이전: 승인 시 공개). 거짓 "비번식 확인" 체크를 막을 수단은 CAPTCHA뿐.
  2. 보호가 필요한 사례: 흰꼬리수리·검독수리·수리부엉이·올빼미(둥지 근처 야영·휴식지), 두루미류·황새·저어새·노랑부리저어새(월동·휴식지 교란), 넓적부리도요(멸종위기 1급, 탐조객 쏠림), 팔색조·뿔쇠오리.
  3. 선택지(각각 별도 승인 필요): (a) 현행 유지, (b) 19종은 자동 공개하되 대략점만, (c) 19종은 이전처럼 승인 후 공개, (d) 일정 기간 지연 공개.
