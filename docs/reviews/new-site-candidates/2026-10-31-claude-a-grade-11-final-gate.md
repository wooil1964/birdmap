## 7. 커밋·PR 준비 가능 여부

- **로컬 커밋 준비 가능**: 초안은 기준선 대비 신규 회귀 실패 0이다. 6항 반영 여부를 정한 뒤 커밋할 수 있다(사용자 승인 필요)
- **PR 생성**: 검토용 초안 PR은 승인 시 가능하다
- **병합은 불가**: main 병합은 곧 Pages 공개다. 승인된 순서는 Worker → D1 → Pages이므로 D1 확인과 등록 전에는 병합하면 안 된다

## 8. 운영 등록 전 최종 사용자 승인 사항

1. Wrangler 토큰 갱신(1항 명령) → 읽기 전용 D1 검사 재실행 허가
2. 변경 제안 P1~P5 반영 여부
3. 246 마동호를 이번 등록에서 뺄지(빼면 총 239곳, ID 246 예약) 또는 기관 확인까지 전체를 미룰지
4. 커밋, 검토용 PR 생성
5. Worker 사이트 목록 배포 → D1 원자 추가 → Pages 병합, 단계별 승인
