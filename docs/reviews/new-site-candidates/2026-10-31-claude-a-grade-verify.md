## 5. 시험·확인 결과

- 런타임 탐조지 229곳 추출, id 중복 없음 확인(`sites.js` 객체 키)
- 카카오맵: 내장 브라우저에서 카카오맵 페이지 자체 검색 요청의 응답만 읽음(스크립트 직접 호출은 403). 각 후보의 주소 시군구가 지역 칸과 일치
- OSM: Nominatim 검색(범위 제한 포함). Overpass는 응답 지연으로 중단
- 기준 엑셀(v21·v24) 열람은 못 함(이 PC Python에 openpyxl 없음). 그래서 **엑셀에 이미 있는지 여부는 미확인**
