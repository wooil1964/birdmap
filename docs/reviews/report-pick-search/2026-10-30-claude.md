## 1. 작업 목적

`📍 출현종 제보하기` → 제보 위치 선택창을 작게 줄이고, 기존 GPS·지도 지정은 그대로 둔 채 주소·장소명 검색을 넣는다.
검색 결과는 지도만 옮기고, 실제 제보 위치는 지도 터치(또는 GPS)로만 확정한다.

## 3. 변경 내용

### 화면

- 1줄: 왼쪽 `제보 위치 선택`, 오른쪽 끝 닫기 `×`
- 2줄: 왼쪽 `현재 위치` 버튼(GPS 아이콘), 오른쪽 `주소·장소명 검색` 입력창(돋보기 아이콘)
- 하단 `취소` 버튼 숨김(×가 같은 `cancelReportPicking()`을 호출)
- 위치를 고르기 전 안내문(“현재 위치를 사용하거나 지도를 눌러…”)은 숨김. 위치를 고르면 기존처럼 상태 문구와 `이 위치로 제보` 버튼이 나타남
- 폭 340px → **248px**(작은 화면은 `100vw − 16px`), 높이 PC 약 85px·모바일 약 100px
- PC·모바일 같은 배치. 터치 기기는 버튼·입력창 44px, 입력 글자 16px(iOS 확대 방지)
- GPS 버튼 문구: `현재 위치` / 확인 중 `확인 중…` / GPS 위치 후 `다시 찾기`. 제보 입력창 안의 GPS 버튼 문구(`현재 위치 사용`)는 그대로

### 검색

1. Enter(모바일 키보드 `검색`)로만 검색. 입력 중 자동완성 호출 없음
2. 결과 최대 3건(중복 제거), 장소명 + 짧은 주소(`경상남도 창원시 의창구 주남로`)
3. 결과 선택 → 지도를 해당 좌표 줌 16으로 이동, 결과창 닫힘, `지도를 눌러 발견 지점을 지정하세요.` 표시
4. 결과 선택만으로는 `reportPicked`가 바뀌지 않음(확정 버튼도 안 나타남). 지도 터치·GPS 시 기존 코드가 위치 확정
5. 결과 없음: `검색 결과가 없습니다.` / 실패: `검색하지 못했습니다. 지도에서 직접 지정해 주세요.`
6. 같은 검색어는 메모리 캐시, 호출 간격 최소 1.1초, 8초 시간 제한, 쿠키 미전송
7. 모바일 키보드: `visualViewport` 기준으로 패널을 키보드 위로 올림. 가로 화면처럼 공간이 좁으면 결과 목록만 스크롤

### 검색 서비스 선택

| 후보 | 판단 |
|------|------|
| **OpenStreetMap Nominatim (채택)** | 인증키 없음 → 노출 위험 없음. CORS 허용이라 브라우저에서 바로 호출, Worker·D1·인프라 변경 없음. 한국 탐조지명·도로명 주소 실측 양호(주남저수지·을숙도·시화호·천수만·순천만습지·세종대로 110 등) |
| VWorld 검색 API | 키가 Worker 비밀값이라 브라우저에 넣으면 노출, 중계를 쓰려면 Worker 변경 필요 → 이번 범위(인프라 변경 금지) 밖 |
| 카카오 로컬·지도 SDK | 앱 등록·JavaScript 키(도메인 제한) 발급 필요, 타 지도 위 표시 관련 약관 검토 필요 → 품질은 더 좋을 가능성, 후속 검토 대상 |

Nominatim 이용 정책(https://operations.osmfoundation.org/policies/nominatim/, 2026-10-30 확인) 준수 내용:

- 앱 전체 합산 **초당 1회 이하** → Enter 전용·1.1초 간격·캐시로 대응. 이용자 수가 매우 많아지면 합산 기준을 넘을 수 있음
- **자동완성 금지** → 입력 중 호출 없음
- 앱 식별(Referer/User-Agent) → 브라우저가 사이트 Referer를 보냄
- **출처 표시** → 결과 목록 아래 `© OpenStreetMap`
- 요청 시 **코드 수정 없이 끌 수 있어야 함** → `assets/birdmap-report-pick-search.js` 맨 위 `SEARCH_URL`을 `''`로 바꾸면 검색창만 사라지고 나머지(축소 패널·GPS·지도 지정)는 유지
- 개인정보 제출 금지 → 검색어 외 위치·제보 정보는 보내지 않음(사용자가 집 주소를 입력하는 것까지는 막을 수 없음)
- 비용: 무료(기부 서버, SLA 없음). 정책은 예고 없이 바뀔 수 있고 과다 사용 시 차단될 수 있음. **추가 비용 없음**, 차단 시 유료 대안(카카오·상용 지오코더) 필요

## 6. 기존 기능 영향

- 제보 저장 절차·민감종/번식 보호·위치 가리기: 관련 코드 무변경(index.html 본문 무변경). 검색은 지도 이동만 하고 제보 좌표·서버 전송 경로를 건드리지 않음
- GPS: 기존 `useCurrentReportLocation()` 그대로, 버튼만 패널 안에서 위치 이동·문구 단축
- 지도 지정: 기존 `reportMapClick` 그대로. 확대/축소 버튼 클릭은 여전히 위치로 잡히지 않음
- OSM/VWorld 전환, 카카오맵·티맵 길찾기, 내 위치 찾기: 해당 코드 무변경, 회귀 스위트 통과
- 설치 실패 시(요소 누락 등) 패널은 예전 모양 그대로 남음(`.rpsCompact` 미부여)

## 7. 미해결 문제·남은 위험

- **Android 실기기 시험 미실시.** 키보드는 `visualViewport`를 흉내 낸 자동 시험만 통과 — 실기기 Chrome·삼성 인터넷에서 확인 필요(“통과”로 보고하지 않음)
- iOS Safari 미확인
- Nominatim 품질: 지번 주소·상호명은 OSM 수록 여부에 좌우. 결과 없음일 때는 지도에서 직접 지정
- Nominatim 공용 서버는 무료·무보증. 이용량이 커지면 정책 위반·차단 가능 → 그때 카카오 등 키 기반 서비스 검토
- 위치를 고르기 전 안내문을 숨겼으므로 처음 쓰는 사람에게 “지도를 누르라”는 안내가 약해질 수 있음(검색 결과 선택 후에는 안내 표시). 필요하면 CSS 1줄로 되돌림
