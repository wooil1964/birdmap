## 1. 작업 목적

PR #96의 "종명이 불명확하면 제보 전체 공개 차단" 요구를 폐기하고 2026-11-14 사용자 최종 정책을 적용한다.

1. 단순 문장부호 오기는 읽기 단계에서 정규화하고, 공식 국명과 정확히 일치하면 확정 종으로 센다(`호사비오리'` → 호사비오리 1종, `호사비오리' 3마리` → 1종 3개체).
2. `?`·`추정`·`류` 등 동정 불확실 표현과 공식 목록에 없는 이름은 **분류 미확인**: 관리자 승인 후 공개, 명확한 개체수는 전체 개체수에 포함, 확정 종수에서는 제외.
3. 정규화 전 원문은 보존한다. 영명·학명의 정상 문장부호는 지우지 않는다.
4. 종명 분류와 위치 공개 판단은 분리한다. 정규화된 확정 종명에 보호종·번식 위치 정책을 적용해 문장부호 오기가 위치 보호 우회 수단이 되지 않게 한다.

(최초 지시였던 "`호사비오리'`를 분류 미확인으로 처리"는 사용자 최종 지시로 취소되어 2번째 커밋에서 대체했다.)

- 승인된 분류 미확인 기록이 지도·검색·이력에 다시 보인다(PR #96 대비 공개 범위 확대, 사용자 정책).
- 회원·관리자·최근 탐조지 종수가 분류 미확인만큼 줄고, 관리자 개체수는 분류 미확인의 명확한 수량만큼 늘 수 있다.
- 과거 원문 `이름+숫자`(공식 국명이 아닌 이름)의 개체수가 관리자 통계·공개 상세에 새로 잡힌다.
- 자동 공개(승인 전) 판정, 위치 가리기, 번식 차단, 동일인 그룹 계산은 바뀌지 않았다.

## 7. 남은 위험·미확인

- **배포 순서**: 새 Worker의 `/reports/reporter-species`는 분류 미확인 이름이 있을 때 `unclassified` 키를 보낸다. 현재 운영 index.html은 모르는 키가 있으면 목록 표시를 거부하므로 **Pages(index.html)를 먼저 반영한 뒤 Worker를 배포**해야 한다. 새 index.html은 키가 없는 기존 Worker와도 동작한다.
- 공식 국명과 정확히 일치할 때만 정규화한다. `(호사비오리)`처럼 괄호로 감싼 경우, 공백이 끼어든 경우, 제로폭 문자는 분류 미확인으로 남는다(위치는 계속 보호). 확대 여부는 사용자 결정 사항.
- 관리자 종명 정정은 기존처럼 `reports.species`를 바꾸므로 원본 비번식 확인이 무효가 되어, 정정된 보호종 기록의 좌표는 다시 비공개가 된다(안전 방향, 기존 동작).
- 학명·영명과 국명이 섞인 같은 종(`넓적부리도요`와 `Calidris pygmaea`)을 하나로 합치지 않는 기존 종수 한계는 이번 범위 밖.
- 회원별 공개 통계에는 개체수 항목이 원래 없다. 회원 개체수는 관리자 제보자별 통계에서만 확인된다.
- 운영 D1 실제 자료의 영향 건수는 조사하지 않았다(운영 접근 금지).
- 지도 툴팁·최근 제보 목록 등 텍스트 전용 목록은 원문 종명만 보이고 "(분류 미확인)" 표시는 기록 상세·회원 종명 목록·관리자 통계에만 붙는다.
