# 전국탐조지도 비번식 제보자 선택 정책 (2026-11-14)
이 문서는 PR #96의 운영 전 검증 기준이다.

- 보호종, 희귀종, 일반종의 국명이 명확하고 원본에 **비번식 확인**이 있으면, 종명 자체를 숨기지 않는다.
- 좌표는 제보자가 선택한 \`hideLocation\`을 따른다. 해당 제보의 원본 비번식 증거가 변조되거나 내용이 변경되면 공개 허가는 무효가 된다.
- **모든 조류**의 둥지·포란·육추 등 번식 관련 관찰에서는 정확한 좌표를 공개하지 않는다.
- \`호사비오리'\`처럼 해석이 불명확한 종명은 조류 보호 지정 여부와 무관하게 공개를 보류한다. 원문을 자동 교정하거나 일반종으로 대체하지 않는다.
- 기존에 저장된 보호종 중 비번식 확인 증거가 불충분한 행은 이번 변경만으로 **정확 좌표를 소급 공개하지 않는다**.
- 현장소식은 같은 위치 공개 원본 확인 수단이 없어 기존의 보호종 좌표 마스킹 정책을 유지한다.
- 집계용 종명 목록은 위치를 제공하지 않는다. 보호종 또는 제보자 위치 가리기만으로 이름을 통째로 제외하지 않는다.
- \`REPORTS_IDENTITY_AUTO_ALIASES\` 설정과 보호종/번식 정책은 별개이며 기존 PR #95의 동일인 그룹 데이터 및 운영 D1은 절대 수정하지 않는다.

승인 전: 회귀·브라우저 CI, 독립 합성 시나리오, 구형 Worker 및 운영 D1 스냅샷과의 일치성 검증 필요. 운영 DB 변경, 배포 및 병합 금지.
