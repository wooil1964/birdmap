# 누적 출현 제보 통계 팝업 스크롤 개선 (2026-11-11, Claude Code)

## 1. 작업 목적
「누적 출현 제보 통계」 팝업이 PC·모바일 모두 화면 높이 안에 들어오고, 제목·닫기는 고정한 채
그 아래 내용(근거 문구·통계 수치·검색창·과별 출현종 표)만 세로 스크롤되게 한다.
모바일에서 목록 맨 아래까지 스크롤할 수 있게 한다.

## 3. 변경 내용
원인: 통계 팝업은 공통 `.monthTideDialog` 규칙을 그대로 써서 최대 높이가
`calc(100vh - 56px)`(모바일 `calc(100vh - 16px)`)였다. 실제 휴대폰의 `100vh` 는 주소창·툴바가
숨었을 때의 큰 높이라, 툴바가 보이는 동안에는 팝업이 실제 보이는 영역보다 길어진다.
가로 화면(폭 700px 초과)은 가운데 정렬이라 위(제목)와 아래(목록 끝)가 함께 잘린다.
또 근거 문구 2줄이 스크롤 밖에 고정돼 작은 화면에서 목록 공간을 줄였다.

- HTML: 근거 문구(`#reporterStatsBasis`)와 내용(`#reporterStatsContent`)을 새 `div.reporterStatsBody` 로 감쌌다.
  id·aria 속성·텍스트는 그대로다.
- CSS: `#reporterStatsModal .monthTideDialog` 에 `max-height:100%` 추가(바깥 고정 상자 = 실제 보이는 영역 기준).
  `.reporterStatsBody{flex:1 1 auto;min-height:0;overflow-y:auto;overscroll-behavior:contain}` 추가.
- 모두 `#reporterStatsModal` 안에서만 적용된다. 공통 `.monthTide*` 규칙은 건드리지 않았다.
- JS(집계·검색·공개 정책·포커스 순환) 변경 없음.

## 6. 기존 기능 영향 여부
- 누적 출현종 수·승인 제보 건수·과별 종수 계산, 검색, 공개 정책·개인정보 보호 코드는 바뀌지 않았다.
- 같은 공통 규칙을 쓰는 다른 팝업(월간 조석·기여자·승인 제보 전체 보기·출현종 제보)의 최대 높이는
  기존 그대로 `calc(100vh - 56px)` 로 측정됐다.
- 글자 크기 유지 확인: 제목 17px, 근거 12px, 수치 22px, 표 13px(PC). 팝업 폭 380px 그대로.
- 동작상 차이 1가지: 근거 문구 2줄이 이제 고정이 아니라 내용과 함께 스크롤된다(요청: 제목 아래 내용만 스크롤).

## 7. 발견된 미해결 문제
- 실제 iOS Safari·Android Chrome 기기에서는 확인하지 않았다. 툴바 가림은 바깥 상자 높이를 줄여 재현했다.
- 종 목록을 열면 검색창에 자동 포커스가 가서 모바일 키보드가 올라온다. Android Chrome 기본 설정에서는
  키보드가 화면을 줄이지 않으므로, 키보드가 떠 있는 동안 목록 아래쪽은 키보드에 가린다(키보드를 내리면 끝까지 스크롤됨).
  자동 포커스 변경은 이번 범위 밖이라 그대로 두었다.
