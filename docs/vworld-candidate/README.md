## 상담 확인과 기술 검증의 구분

사용자는 2026-10-22 브이월드 상담센터에 직접 문의하여 개발키로 서비스를
이용하다 같은 키가 운영키로 자동 전환되는 방식을 허용·추천한다는 안내를
받았다고 확인했다. 개발키 신청 때 등록한 주소는
`https://wooil1964.github.io/birdmap/`이다. 이는 사용자 직접 확인 사항이다.
이전 문서의 '운영기관 허용 확인 대기'는 이 확인으로 대체한다.

사용자는 이후 직접 WMTS와 Cloudflare Worker 중계도 모두 허용받았다고 확인했다.

요청과 지도 표시를 별도로 확인했다. 키는 사용자가 임시 암호 칸에 입력했으며
소스·로그·아티팩트에 저장하지 않았다. 이후 무관한 HTTPS 출처의 허용을 추가 확인했다.

## 지도 선택과 복귀

저장된 선택이 없으면 VWorld를 선호한다. 기본 Worker 모드에서 승인된 공개 endpoint가
공급되고 국내 중심 범위·줌 6 이상이면 VWorld, 설정 없음·국내 범위 밖·작은 축척에서는 OSM이다.
사용자가 OSM을 선택하면 저장한다. 지원 범위로 돌아오면 VWorld 선호를 복원한다.
이 국내 중심 범위는 앱 정책이며 공식 WMTS 제공 경계가 아니다.

타일 오류 누적 3회, 배치 전체 실패(1~2개 포함), 배치 12초 미완료 때 OSM으로
복귀한다. 실패한 같은 Worker endpoint의 자동 재시도는 현재 세션에서 잠그며 사용자가
'다시 시도'를 누르면 해제한다. 부분 성공과 오류 1~2개가 함께 있으면 안내 후
VWorld를 유지한다. HTTP 200으로 정상 디코딩되는 빈 타일은 판별하지 못한다.
좌표·줌·마커·검색·필터·제보 선택 상태는 바탕지도 교체 대상이 아니다.

`assets/map-runtime-config.js`는 키 없는 실행 설정이다. 승인된 배포 시
Worker endpoint만 제공할 별도 승인된 배포 절차가 필요하며 이번에 배포하지 않는다.
VWorld 키는 독립 Worker secret으로만 공급하는 방식을 검토했다.
직접 WMTS 요청 방식의 키는 배포 시 이미지 src·Network·Leaflet 메모리에
나타난다. 저장소에 키를 넣지 않는 것만으로 방문자에게 숨길 수는 없다.
키가 든 HAR·URL·오류 이벤트·브라우저 저장소·스크린샷은 수집하지 않는다.
허용받은 서버 중계만 추가하며 인증 우회·타일 저장·캐시는 추가하지 않는다.

## 시험 환경

`server.mjs`는 루프백 GET과 명시된 공개 파일만 제공하는 비교 서버다.
`connect-src 'self'`, form/frame 차단으로 운영 API 쓰기를 막는다.
직접 열면 공개 CDN·OSM 이미지 GET은 가능하다. 자동 브라우저 검사는
모든 VWorld/OSM 타일을 합성 PNG 또는 오류로 바꾸고 Worker 응답을 모의한다.
운영 제보 제출·운영 DB 쓰기는 하지 않는다.

모의 타일 성공을 실제 VWorld 서비스 성공으로 표현하지 않는다. 데스크톱
브라우저의 모바일 화면·터치 모의를 실제 휴대전화 통과로 표현하지 않는다.
실제 등록 Pages 출처의 실타일 인증·표시는 완료했다. 실제 Android/iOS, GPS·핀치·
지도 앱 실행은 별도 범위로 남아 있다. 등록 외 도메인 요청은 실제로 허용됐으며
새 Worker의 실제 Cloudflare 송신/인증은 배포 승인 후 확인해야 한다.

```text
node --test .github/scripts/test_basemap_controller.mjs .github/scripts/test_basemap_server.mjs
node docs/island-nearby-pilot/browser.mjs
node docs/vworld-candidate/browser.mjs
```

키 없는 자동 검증과 실제 Pages 검증의 증거를 구분한다.
검토 소스의 키는 계속 비어 있다. VWorld 운영 활성화는 승인된 배포 단계의
키 공급 설정과 사용자의 최종 승인이 필요하며 이번에 수행하지 않는다.
