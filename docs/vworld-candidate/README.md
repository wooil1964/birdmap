# VWorld 기본 지도 변경 후보

2026-10-21 · 키 없는 검토 후보. 이 변경은 운영 배포를 수행하지 않는다.

## 운영 판정: 보류

사용자는 개발키 운영을 승인했지만 공개 운영 허용 여부를 먼저 확인하도록 했다.
[현행 공식 약관](https://www.vworld.kr/v4po_prcint_a001.do#jump1) 제2조①10은
개발 목적의 개발키와 서비스 운영 목적의 운영키를 구분하고, 제15조①5 및
제16조④는 운영키 신청과 심사를 규정한다. 심사 대기 중 개발키로 공개 운영할
수 있다는 예외를 확인하지 못했으므로, 이 후보에는 키를 넣지 않고 운영키 승인
또는 운영기관의 명확한 허용 확인을 기다린다. 개발키 사용이 전면 금지됐다고
확대 해석하지 않는다. 2026-10-30 시행 개정본도 목적 구분과 심사 절차를 유지한다.

비교 기준은 main `fbe631d4c8090c9e87e6c4d13cb38a2ff11561ec`이다. 이전 후보
기준 `a2d9df3528d9e5fbfee1f6898cd02e3abb5a0c40`과의 차이는 기상 JSON 두
파일뿐이며 지도·제보 코드는 동일하다. 운영 페이지의 index 파일도 main과 같음을
읽기 전용으로 확인했다. 이 PR은 운영 데이터와 API 구현을 바꾸지 않는다.

## 동작

저장된 사용자 선택이 없으면 VWorld를 선호한다. 유효한 실행 설정이 있고,
기존 국내 중심 범위 안이며 줌 6 이상일 때 VWorld 바탕지도를 사용한다.
사용자가 OSM을 고르면 그 선택을 저장한다. 좌표·줌·마커·검색·필터·제보
선택 상태는 바탕지도 전환 대상으로 삼지 않는다.

키 없는 검토 소스에서는 OSM을 표시한다. 작은 화면 전국 보기나 국내 범위
밖에서도 OSM을 사용하며, VWorld 선호 상태라면 지원 조건으로 돌아올 때
VWorld를 다시 사용한다. 이 범위는 앱 정책이고 공식 WMTS 제공 경계가 아니다.

타일 오류 누적 3회, 배치 전체 실패(1~2개도 포함), 배치 12초 미완료 시 OSM으로
복귀한다. 동일 키의 재시도는 현재 컨트롤러 세션에서 잠그며 화면 이동이나
지도 재선택으로 풀리지 않는다. 사용자가 '다시 시도'를 누르면 풀린다.
부분 성공과 오류 1~2개가 함께 있으면 안내 후 VWorld를 유지한다.
HTTP 200으로 디코딩되는 빈 그림은 판별하지 못한다.

## 파일과 실행 설정

- `index.html`: 기존 카메라 맞춤 후 선택기를 연결하는 최소 변경.
- `assets/birdmap-basemap.js`: 바탕 타일 전환·오류 정책.
- `assets/birdmap-basemap-init.js`: 기존 화면에 연결하고 설정 전역 참조 정리.
- `assets/birdmap-basemap.css`: PC·모바일 선택 버튼.
- `assets/map-runtime-config.js`: **키가 비어 있는 예시**. 검토 소스에 키를 넣지 않는다.

실제 서비스 연결은 약관·계정·등록 도메인 요건 충족 후 실행 설정을 제공해야 한다. 사용자에게 앞서
입력받은 키는 보관하지 않았고 재사용하지 않았다. 배포 절차는 아직 구성·실행하지
않았다. 브라우저가 타일을 직접 요청하므로 키는 실제 통신 URL과 Leaflet 메모리에
존재한다. 설정 전역 참조 삭제로 브라우저 노출까지 없어지는 것은 아니다.
키는 타일 이미지의 src에도 들어가며, 실제 키를 넣은 runtime-config.js는 브라우저에서
읽을 수 있다. 키 없는 저장소와 배포 비밀 저장소만으로 방문자에게 키를 숨길 수 없다.
키가 든 HAR·요청 URL·오류 이벤트 전체·브라우저 저장소·화면 캡처를 수집하지 않는다.
공식 FAQ의 URL/domain 안내만으로 WMTS의 Referer 검사, 하위 도메인·프로토콜·포트·경로
매칭을 확정하지 않는다. 이 계정의 등록 도메인과 실제 허용/거절 동작은 미확인이다.
인증·도메인 제한을 우회하는 프록시나 허가 없는 타일 저장·재배포를 추가하지 않는다.

## 시험과 제한

새 컨트롤러 검증은 모두 로컬 모의 타일을 사용했다. 이전 어댑터의 실제 타일 성공을
이 새 코드의 실타일 통과로 옮겨 주장하지 않는다. 실제 휴대전화, 실제 앱 실행,
운영키 승인·등록 도메인·만료일, 별도 HTTPS 시험 환경의 제보 접수는 남아 있다.
운영 D1에는 테스트 제보를 쓰지 않았다.

`server.mjs`는 개발용 보호 서버다. 저장소 루트에서
`node docs/vworld-candidate/server.mjs`로 연다. 루프백에서 GET만 받고,
`connect-src 'self'`와 form/frame 차단으로 기존 운영 API 쓰기를 막는다.
OSM 타일·CDN 등 외부 GET까지 막는 서버는 아니다. 자동 회귀에서는 브라우저
라우팅으로 모든 OSM/VWorld 타일을 로컬 그림으로 바꾸고 외부 쓰기와 운영 API를
추가 차단했다. 서버의 직접 열기와 모의 회귀의 통신 범위를 혼동하지 않는다.

보호 서버는 정확히 지정한 공개 실행 파일만 제공하고 대소문자 변형·숨김파일·경로
이탈·외부 Host·디렉터리 링크 이탈을 차단한다. Windows 대문자 경로로 버전관리 제외
로컬 설정에 접근할 수 있던 이전 후보의 문제를 수정했다. 원래 설정파일은 읽지
않았으며, 시험은 임시 폴더의 합성 표식만 사용했다.
`/baseline` 비교 화면은 후보 커밋의 HEAD 대신 위 main 기준 커밋으로 고정해,
후보를 커밋한 후에도 원래 운영 코드와 비교한다.
