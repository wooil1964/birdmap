탐조 준비 흐름
① 가고 싶은 곳 검색
→ ② 지도웹으로 교통 확인
→ ③ Windy로 날씨 확인

기본 사용법
  1. 검색창에 탐조지명, 지역명, 국가명, 종명을 입력합니다.
  2. 검색 결과 목록을 누르면 해당 마커로 이동합니다.
  3. 계절·희귀조·미기록·섬탐조·선상탐조 필터로 좁혀 봅니다.
  4. 마커를 누르면 대표종, 접근정보, 주의사항이 나옵니다.
  5. 네이버지도는 교통·주변시설 확인, 카카오맵은 엑셀 좌표 확인에 씁니다.
  6. Windy로 바람·비·파도 확인 후 탐조일을 정합니다.
  7. 섬탐조는 KSA 여객선에서 배편을 확인합니다.
